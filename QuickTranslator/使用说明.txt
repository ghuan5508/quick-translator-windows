快速截图翻译（Windows）

功能
- 后台托盘常驻，默认全局热键 Alt+Q。
- 框选屏幕上的文字，使用 Windows OCR 识别。
- 翻译结果显示在置顶窗口，可在无边框全屏游戏上方查看。
- 默认识别英文并翻译成简体中文；设置面板可选英文、日文、韩文或中文 OCR，以及翻译方向。
- 使用免密 MyMemory 在线翻译；需要联网。关闭联网后，英文可尝试内置词典，其他语言需要联网。

构建
1. Windows 10/11 安装 .NET 9 SDK。
2. 在本目录运行 PowerShell：.\build.ps1
3. 单文件程序生成到 publish\QuickTranslator.exe。此版本自包含 .NET 运行时，不需要另装 .NET Runtime。

首次使用
1. 双击 publish\QuickTranslator.exe。
2. 按 Alt+Q，拖动框选游戏文本。
3. 查看置顶翻译窗口；按 Esc 关闭。
4. 右键托盘图标可以打开设置或退出。

注意
- 在线翻译会把识别出的文字发送到 MyMemory，且需要联网；免费服务可能有请求次数或可用性限制。
- Windows OCR 只能识别系统已安装的对应语言包。若某语言识别失败，请在 Windows 语言设置中安装该语言的 OCR 功能。
- 置顶窗口通常能覆盖无边框全屏游戏；独占全屏或反作弊保护的游戏可能压住桌面窗口。
- 这是免安装单文件 EXE，不是带安装向导的安装包。
